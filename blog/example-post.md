## Adding a post

1. Write `blog/my-slug.md`.
2. Add an entry to `posts.json` (newest first).

That's it — no build step, no generator.

## What renders

Body text with **bold**, *italic*, `inline code`, and [links](https://github.com/AniLeo-01).

```python
def hello():
    return "world"
```

> Blockquotes work too.

- Lists
- Tables
- Images

| Thing | Supported |
| --- | --- |
| GFM tables | yes |
| Footnotes | no |
